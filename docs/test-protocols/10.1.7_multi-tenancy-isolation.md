## Setup: Obtain Tokens

Before running tests, obtain tokens for different users and identify company IDs.

```bash
# Admin token (root admin — has access to initial company)
ADMIN_TOKEN=$(curl -s -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"SecureP@ss2024!"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")

# ALC user token (member of ALC Corporate company only)
ALC_USER_TOKEN=$(curl -s -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"alc-user","password":"AlcCorp2024!"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")

# ALC IT Admin token (system_admin of ALC Corporate only)
ALC_ADMIN_TOKEN=$(curl -s -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"alc-it-admin","password":"AlcCorp2024!"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")
```

Identify company IDs:

```bash
# List companies (root admin)
curl -s http://localhost:8080/api/companies \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "X-User-Id: 1" | python3 -c "
import sys, json
companies = json.load(sys.stdin)
for c in companies:
    print(f'id={c[\"id\"]} slug={c[\"slug\"]} name={c[\"display_name\"]}')"
```

Expected: At least 2 companies — the initial setup company (id=1) and ALC Corporate (slug=alc-corporate).
